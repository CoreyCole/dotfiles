# Pi OpenAI Fast

This extension is vendored from `studioarray/pi-openai-fast` at commit `e82ed32f1b7c5a946d441d948da33de40da7b04a`.

Upstream repository: <https://github.com/studioarray/pi-openai-fast>

The vendored extension keeps the upstream `/fast`, `--fast`, settings, request injection, warnings, and child-process handoff behavior.

The global settings use status mode. The custom Pi footer places the active `fast` label after the model and thinking level.

The MIT license from the upstream repository is in `LICENSE`.
